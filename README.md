# 🐾 등원 대작전 · 우리집 등원 대시보드

아이패드를 가로로 세워 두고 보는 **등원 준비 전용 대시보드**입니다.
아이(인성 대원)가 아침 루틴을 직접 톡톡 눌러 체크하고, 엄마·아빠 폰과 실시간으로 맞춰집니다.

- 주소: <https://jongheeyi-crypto.github.io/home/>
- 화면: 상단 히어로(실시간 시계·날씨·출발 카운트다운) + 3열 카드(루틴 / 준비물·알림 / 일정·바로가기)
- 대상 화면: iPad 가로 `1180×820`, `1024×768`, `1366×1024`에서 스크롤 없이 한눈에 / 휴대폰은 1열로 자동 정리

| 📅 우리집 일정 | 요일별 가족 일정(등원·할머니집·수영 등)과 미션판·냉장고 바로가기 |
| ⚙️ 엄마 설정 | 출발 시간, 루틴·준비물·일정 편집, 오늘 체크 초기화, 가족 링크 복사 |

식단은 이 화면에 넣지 않았습니다(별도 냉장고 페이지에서 확인).

## 날씨

주소를 노출하지 않고 좌표(목동)만으로 [Open-Meteo](https://open-meteo.com/)에서 현재·체감 기온,
최저/최고, 강수확률, 미세먼지(PM10/PM2.5)를 받아 옵니다.
기온·날씨 코드에 따라 `두꺼운 외투 입어요 🧥`, `비 예보! 우산 챙겨요 ☔`, `미세먼지 나쁨 · 마스크 😷` 같은
아이 눈높이 팁을 자동으로 보여 줍니다. 통신이 막히면 기본 안내 문구로 조용히 대체됩니다.

## 실시간 동기화 (엄마 폰 ↔ 아이패드)

- Firebase Realtime Database(무료 Spark) 익명 로그인 사용, 방 코드는 `?room=` 주소와 브라우저 저장소에만 있음
- 체크·메모·설정을 `updatedAt` + `clientId` + 날짜별 기록으로 병합해 두 기기가 서로 덮어쓰지 않음
- 날짜(Asia/Seoul)가 바뀌면 그날 체크만 새로 시작(설정·준비물 목록은 유지)
- 상단 배지가 `🟢 실시간 연결됨`이면 연결 완료, `⚪ 이 기기만 저장 중`이면 방 코드 없이 로컬로만 동작

## 만든 방식

- 빌드 도구 없이 `index.html` + `styles.css` + `app.js` 정적 파일 (GitHub Pages)
- 캐릭터는 저작권 이미지를 쓰지 않고 모두 손으로 그린 SVG (체이스·마샬·스카이·러블·로키·주마 느낌)
- 공개 저장소이므로 실명·전화번호·주소·유치원 이름·실사용 방 코드는 넣지 않았고,
  `<meta name="robots" content="noindex, nofollow">`로 검색 노출을 막았습니다.
- 아이패드 홈 화면 추가용 메타 태그와 `apple-touch-icon.png` 포함

## 설정·사용 팁

1. 아이패드 Safari에서 주소를 연 뒤 **공유 → 홈 화면에 추가** (전체 화면 앱처럼 열림)
2. `⚙️ 엄마 설정 → 실시간 연결 → 새 방 만들기` 후 `🔗 가족 링크 복사`
3. 그 링크를 엄마·아빠 폰에 붙여 넣으면 세 기기가 같은 화면을 봅니다
4. 출발 시간과 요일별 준비물·일정은 `⚙️ 엄마 설정`에서 바로 고칠 수 있습니다
